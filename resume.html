📄 Resume Guidance

Build a resume that gets you to the interview stage

❌ Common Mistakes

  • Generic objective statement ("To work in a challenging environment...")
  • Using "responsible for" instead of action verbs
  • Including photos, DOB, religion, marital status
  • Exceeding 1 page for freshers
  • Spelling and grammar errors
  • Listing every project without context

✅ Best Practices

  • Start bullet points with strong action verbs: Built, Designed, Optimized, Led...
  • Quantify your impact: "Reduced load time by 40%", "Led a team of 5"
  • Tailor your resume for each company/role
  • Use a clean, ATS-friendly format
  • List projects with: Name | Tech Stack | What it does | Impact
  • Keep it to exactly 1 page as a fresher

Action Verbs to Use

Built / Created
Developed, Built, Engineered, Designed, Architected, Launched
Improved
Optimized, Refactored, Enhanced, Streamlined, Accelerated, Boosted
Led / Managed
Led, Managed, Coordinated, Spearheaded, Directed, Organized
Analyzed
Analyzed, Researched, Identified, Evaluated, Assessed, Investigated

Recommended Resume Sections (in order)

1

Header

Full Name | Phone | Email | LinkedIn | GitHub | Portfolio (optional)

💡 No photo, DOB, or address needed for most tech companies.
2

Education

Degree, Branch, College Name | CGPA | Graduation Year

B.Tech in Computer Science, XYZ Engineering College | CGPA: 8.4/10 | 2025
3

Skills

Organize by category: Languages | Frameworks | Tools | Databases

Languages: Python, JavaScript, Java | Frameworks: React, Node.js | Tools: Git, Docker
4

Projects (Most Important!)

2-3 strong projects. Each with: Name | Tech Stack | 2-3 bullet points with impact.

PlacePro – Student Placement Platform | React, Node.js, MongoDB
• Built full-stack platform serving 500+ students
• Reduced average prep time by 30% via targeted practice modules
5

Experience (if any)

Internships, part-time work, research. Role | Company | Duration

6

Achievements & Extra-Curriculars

Hackathon wins, competitive programming rankings, leadership roles, publications.
